## 2. Information Collection and Storage

### A. Local Application Data (On-Device Storage)

**Weapons** is an offline military encyclopedia. It stores your preferences and saved content strictly locally on your device using Android `SharedPreferences`. This includes:

* Saved favorite weapons and historical equipment (Bookmarks / Favorites list)
* Selected interface language preference (e.g., Russian, English)
* Scroll positions and local UI display settings

We do **not** transmit, store, or maintain this data on remote servers. There is no user registration, account creation, or login required to use the application. The entire encyclopedia catalog, including all articles, specifications, and images, operates completely offline.

### B. Automatically Collected Data & Network Usage

* The application contains **no third-party advertising SDKs**, tracking analytics, or user behavior profiling tools.
* The application requires network permissions solely to allow users to optionally navigate to external links (such as viewing the application listing or leaving a review on the Google Play Store).
* We do not collect or log personal identifiers, device hardware serial numbers, GPS location data, or contact lists.
